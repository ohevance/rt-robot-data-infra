# 실험 상세 페이지 — 실험 하나에 한 장 (왜 했나 · 어떻게 · 결과 · 처음 읽는 사람을 위한 분석 · 면접 한 문장)

순서도와 한 표는 [`../EXPERIMENTS.md`](../EXPERIMENTS.md). 각 장은 같은 틀이다: **1. 왜 했나(앞 실험의 어떤 기준을 못 넘어서) → 2. 어떻게 → 3. 결과(원본 파일) → 4. 분석(용어·단위·쉬운 예제·숫자가 말하는 것, 확인/추정 구분) → 5. 면접 한 문장 → 6. 어디에 적혀 있나.**
처음 읽는 사람을 기준으로 썼다 — 용어는 처음 나올 때 풀고, 단위(us·ms·msgs/s·rad)와 계산은 식을 그대로 보인다.
