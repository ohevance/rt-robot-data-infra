# 2분 영상 대본 — "rt-robot-data-infra 가 무엇을 증명하나"

목적: 공고 4항목을 **돌아가는 화면과 숫자**로 2분 안에 보여 준다. 말은 적게, 화면이 말하게. 녹화는 WSL 터미널 + 브라우저(Grafana·GitHub) 화면 녹화(OBS 또는 Windows `Win+G`), 1920×1080, 마이크 내레이션.
총 길이 2:00. 장면 6개. 내레이션은 장면당 2~3문장(한국어 기준 분당 약 250자 → 전체 500자 안).

## 녹화 전 체크리스트 (10분)
- [ ] 터미널 글꼴 크게(18pt 이상), 어두운 배경, 창 2개(노드 / 명령)만.
- [ ] 관제 컨테이너 3개 up, 수집기 `--qos 1`, 가상 장치 50대 `--telemetry-qos 1` 떠 있음. Grafana "Fleet Overview" 탭 열어 두기(Last 5 minutes).
- [ ] 노드는 MuJoCo 파라미터로 띄워 두기. `ros2 daemon stop` 한 번(데몬 RMW 꼬임 방지).
- [ ] GitHub 저장소 Actions 탭을 초록 ✓ 상태로 열어 두기. README 를 "숫자 한눈에" 표가 보이게 스크롤.
- [ ] 표①②③ 파일(`docs/measurements/table*.md`)을 VS Code 미리보기로 열어 두기.

## 장면 1 — 0:00~0:15 — 한 장 요약 (README)
화면: GitHub README 상단 → "직무 요구 ↔ 산출물 ↔ 수치" 표 → 초록 배지.
> "휴머노이드 로봇 회사의 실시간 제어·데이터 인프라 직무를 겨냥해 2주 동안 만든 저장소입니다. 공고의 네 항목마다 코드와 **측정 숫자**, 그리고 매 푸시마다 그걸 다시 증명하는 CI 가 있습니다."

## 장면 2 — 0:15~0:40 — 실시간 루프 (표①)
화면: 터미널에서 `./build/rt_core/jitter_bench --no-rt --seconds 5` 실행 → p50/p99/p99.9/max 출력 → 이어서 `docs/measurements/table1.md` (Pi RT 커널 줄이 있으면 그 줄 강조).
> "1 kHz 제어 루프입니다. 절대 시각 타이머, 락프리 링, SCHED_FIFO — 핵심은 평균이 아니라 p99.9 와 최댓값입니다. 가상 커널에서는 최댓값이 주기 턱밑까지 가고, 실시간 커널에서는 [Pi 숫자] 입니다. 우선순위는 평균을 좋게 하지만 꼬리를 자르는 건 커널입니다."
(※ Pi 실측 전이면 마지막 문장을 "실시간 커널 실측은 Raspberry Pi 에서 진행 중입니다"로.)

## 장면 3 — 0:40~1:05 — ROS 2 노드 + MuJoCo 물리
화면: 노드 터미널(`backend=mujoco` 로그) → 명령 터미널에서 `ros2 topic echo /rt_status --full-length --once` (JSON 에서 `work_us`, `state`, `backend` 를 마우스로 짚기) → `ros2 topic pub ... joint_command` → `ros2 topic echo /joint_states --once` 에서 position 두 번째 값 **−0.180** 을 짚기.
> "제어 코드는 ROS 2 와 무관한 순수 C++ 이고, ROS 2 는 얇은 껍질입니다. 백엔드를 1차 지연 모델에서 MuJoCo 로 바꿨는데 제어 코드는 한 줄도 안 바뀌었습니다. 물리가 들어오자 어깨 관절이 목표보다 1.1도 처집니다 — 중력입니다. 상태 머신은 READY 에서 RUNNING 으로, 워치독은 명령이 끊기면 50 밀리초 안에 멈춥니다."

## 장면 4 — 1:05~1:35 — 관제 + OTA 단계 배포
화면: Grafana 전체 → 명령 터미널 `python3 fleet/ota/rollout.py --version 1.2.0-bad --bad` 실행 → 터미널 타임라인("단계 5%: 3대", "비정상 3/3 → 롤백 결정", "롤백 완료 1.0초") 과 Grafana "펌웨어 버전별 장치 수" 패널이 3대만 튀었다 돌아오는 것을 번갈아.
> "가상 장치 50대가 MQTT 로 관제 서버에 보고합니다. 나쁜 펌웨어를 단계 배포하면 5% — 3대 — 에서 헬스 게이트가 잡아 1초 만에 롤백하고, 나머지 47대는 건드리지도 않습니다."

## 장면 5 — 1:35~1:55 — 장애 주입: 유실 0 의 증거
화면: `python3 fleet/chaos/inject.py --fault broker --duration 10` 실행 → Grafana 초당 메시지가 0 으로 떨어졌다 600 으로 폭주 → 터미널 마지막 JSON 의 `"lost": 0` 강조 → `table3.md` ③-2 표.
> "브로커를 10초 죽이면 장치가 버퍼에 모았다가 재전송하고, 전 장치가 3초 안에 돌아오며 유실은 0 입니다. 처음부터 0 이 아니었습니다 — 측정 방법의 맹점을 고치자 53개가 나왔고, 원인 셋을 추적해 둘은 설정과 종료 처리로 막고 하나는 큐 상한의 설계 수치로 정리했습니다. 그 과정이 전부 커밋에 있습니다."

- 자막은 숫자만(예: "p99 8.5 us", "유실 0/1400", "롤백 1.0초 · 3/50"). 문장 자막은 넣지 않는다.
